# AI_Project

# Proyecto: Sistema de Recomendacion Simple

Este proyecto fue desarrollado como parte de la actividad formativa de GitHub Copilot en Inacap.

El objetivo es explorar como Copilot puede ayudar a generar código relacionado con tendencias emergentes en Inteligencia Artificial.

---

## Pasos realizados

1. Creación de cuenta en GitHub y activación de GitHub Copilot (plan gratuito).
2. Creación del repositorio `AI_Project` en GitHub.
3. Apertura del repositorio en GitHub Codespaces para trabajar directamente en la nube.
4. Creación del archivo `recommendation_system.py`.
5. Uso de GitHub Copilot para generar el codigo inicial de un sistema de recomendacion.
6. Documentacion del proceso en este archivo `README.md`.
7. Commit y Push de los cambios al repositorio remoto.

---

## Codigo generado con Copilot

El archivo principal es `recommendation_system.py`, que implementa un sistema de recomendacion basado en similitud euclídea entre usuarios.
